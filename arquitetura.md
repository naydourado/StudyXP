# Arquitetura do Sistema — StudyXP

O StudyXP será desenvolvido utilizando uma arquitetura modular, separando o sistema em funcionalidades principais. Essa organização facilita o desenvolvimento, manutenção, testes e documentação do projeto.

## Tecnologias utilizadas

- Front-end: React + Vite
- Back-end: FastAPI
- Banco de Dados: MySQL
- ORM: SQLAlchemy
- Documentação da API: Swagger/OpenAPI
